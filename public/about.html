ℹ️ About LilaPHP

LilaPHP was built on the core philosophy that modern web applications do not need bloated ORMs, massive bundles, or multi-megabyte dependencies to be fast, elegant, and secure.

The KISS Philosophy

Keep It Simple, Stupid (KISS) means prioritizing readable, transparent, native PHP 8.x and vanilla web standards over unnecessary abstraction layers.

  • Decoupled Architecture: Nginx serves pure static HTML/CSS/JS without touching PHP. Dynamic operations run strictly under /api/*.
  • Plug & Play Database: Use MySQL by default or switch to portable SQLite (WAL mode) with one line in .env.
  • Zero Build Steps: Pure CSS variables, Vanilla ES6+ modules, and the Lila.js reactive SPA engine.

Built with LilaPHP & Bluebird CSS.
