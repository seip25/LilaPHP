🌐 Static Frontend

Static HTML, CSS, JS served directly by Nginx at C-speed. Zero SSR rendering latency.

⚡ Lila.js Reactive SPA

Lightweight reactive state engine, tagged templates (html`...`), client hash routing, and route guards.

🚀 PHP 8.x REST API

Ultra-fast file-based REST router, CORS preflight handling, and dynamic parameters (/api/users/{id}).

🗄️ Multi-Driver DB

Plug & play support for MySQL (default), PostgreSQL, and portable SQLite with static DB::* helpers.

🔒 Defensive Security

RAM rate limiting, AES-256-GCM authenticated encryption, CSRF tokens, and automated payload sanitization.

🐳 Production Docker

Lightweight containers for Nginx, PHP 8.4-FPM with OPcache/APCu, low-RAM MySQL 8.0, and Redis 7.
