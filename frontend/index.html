Direct File-Based Routing

Nginx directly routes requests to physical files inside backend/routes/*.php. Zero computational routing loops or regex matching.

⚡

OPcache RAM Preloading

In production (`preload.php`), all core classes and models are permanently compiled inside shared RAM for PHP-FPM workers.

💎

Dual-Tier Caching

First-level caching in APCu (native RAM with 0 latency) backed by a secondary Redis Cluster for shared distributed persistence.

🛡️

High-Throughput Security

C-level rate limiting via Nginx (`limit_req`), rapid JSON payload validation, and anti-malware file upload scanning (`Core\Upload`).
