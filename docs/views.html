Frontend Architecture

Native PHP Server-Side Rendering

LilaPHP provides a lightning-fast native PHP view engine. It leverages PHP's built-in output buffering to deliver secure, server-rendered HTML while taking full advantage of OPcache and APCu for caching.

View Architecture & APCu Caching

LilaPHP renders HTML using the \Core\View class. It evaluates pure PHP templates located in the backend/views/ directory.

  • Native PHP Templates: No need to learn a new templating language. Use standard PHP and HTML for maximum performance and full language capabilities.
  • APCu Output Caching: You can optionally cache the final rendered HTML in APCu by passing ['cache' => true]. This skips view evaluation entirely on subsequent requests.
  • Seamless Integration: Views are processed by the same dispatcher as API routes, meaning you can use the same Rate Limiters, CSRF protection, and Middlewares natively on your frontend routes.
  • Clean Variable Extraction: Data passed to the view is automatically extracted into the local scope for clean usage (e.g., <?= $title ?>).

Usage Example

// In your route file (e.g., backend/views/home.php)
<?php
use Core\View;

$data = [
    'title' => 'Welcome to LilaPHP',
    'users' => [/* ... */]
];

// Rendering a view template from backend/views/
View::render('home_template', $data, ['cache' => true, 'cacheTtl' => 60]);
?>
