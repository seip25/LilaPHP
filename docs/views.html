Frontend Architecture

Lila.js Reactive SPA Engine & Bluebird CSS

LilaPHP eliminates the complexity and overhead of heavy frontend frameworks. By default, LilaPHP provides Lila.js — a zero-build, ultra-fast reactive SPA micro-library with tagged template literals (html`...`), hash-based client routing, route guards, and integrated Bluebird UI components.

1. Freedom of Frontend Frameworks

Because LilaPHP uses a 100% decoupled architecture where Nginx directly serves static assets from frontend/ and proxies /api/* to PHP-FPM, you can use Astro, React, Vue, Svelte, or Next.js static exports if you choose.

However, for most projects, Lila.js gives you complete reactive power, client-side routing, modals, toasts, and API consumption with zero build steps and zero npm dependencies.

2. Lila.js Core API

Lila.route(path, config)

Registers a client-side route with initial state, reactive HTML template, onMount lifecycle, and event actions.

Lila.beforeRoute(guardFn)

Asynchronous route guard hook to verify authentication, sessions, or permissions before rendering.

Lila.html`...`

Tagged template literal supporting interpolated values, arrays, nested templates, and sub-components.

Lila.fetch / Lila.api

High-performance HTTP client with automatic CSRF token injection and JSON error parsing.

3. Real-World Interactive SPA Example

<!DOCTYPE html>
<html lang="en" data-theme="dark">
<head>
    <meta charset="UTF-8">
    <title>Admin Dashboard — LilaPHP</title>
    <link rel="stylesheet" href="/css/bluebird.css">
    <script src="/js/lila.js"></script>
</head>
<body>
    <nav>
        <a href="#/" data-link>Dashboard</a>
        <a href="#/users" data-link>Users</a>
    </nav>

    <div id="app"></div>

    <script>
        const { html, route, start, beforeRoute, fetch: http, escapeHtml } = Lila;

        // Session & Auth Route Guard
        beforeRoute(async (path) => {
            const auth = await http('/api/auth');
            if (auth.status === 'success' && auth.authenticated) return true;
            window.location.href = '/login';
            return false;
        });

        // Dashboard Route
        route('/', {
            state: () => ({ stats: {}, loading: true }),
            template: (s) => html`
                <div class="container">
                    <h2>Overview</h2>
                    <p>Active Users: ${s.stats.total || 0}</p>
                </div>
            `,
            onMount: async (state) => {
                const res = await http('/api/dashboard');
                state.stats = res.data;
            }
        });

        start('#app');
    </script>
</body>
</html>
