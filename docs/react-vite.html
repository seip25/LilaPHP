Frontend Architecture

React 19 & Vite Engine

LilaPHP pairs PHP 8.4+ server-side pre-rendering with React 19 SPA client-side hydration, Vite HMR, and ultra-clean declarative view configuration.

ViewEngine Architecture & APCu Caching

LilaPHP renders React SPA HTML shells server-side via \Core\ViewEngine with full APCu template caching for maximum RPS:

  • APCu Template Cache: In production, rendered HTML is stored as raw strings in APCu shared RAM. Subsequent requests serve the cached template in ~0.01ms without any template processing.
  • Server-Side Route Guards: Protected routes are checked server-side BEFORE cache lookup. Unauthenticated users receive an instant 302 redirect without rendering.
  • SEO Metadata Injection: Title, description, and keywords are injected per-route from frontend/index.php configuration arrays.
  • Vite HMR & Production Bundles: In development, Vite React Refresh preamble and HMR client are injected. In production, compiled bundles from _core/cache/build_cache.php are served.
  • Dynamic File-Based Routing: React pages in frontend/src/pages/ are auto-discovered via Vite's import.meta.glob and lazy-loaded with auth guards configured in routes.jsx.

├── _core/

│   └── cache/
│       └── build_cache.php    # Compiled production Vite script & CSS tags
├── frontend/
│   ├── index.php              # Declarative SEO & route middleware configuration
│   ├── js/
│   │   └── .vite/             # Vite production build output directory
│   └── src/
│       ├── main.jsx           # Dynamic file-based router with lazy loading
│       ├── routes.jsx         # Route config, auth flags & import.meta.glob discovery
│       ├── App.jsx            # Main layout wrapper with Outlet
│       ├── components/
│       │   ├── Auth.jsx       # Auth guard (checks /api/auth, shows skeleton)
│       │   └── Public.jsx     # Public route passthrough wrapper
│       └── pages/
│           └── Home.jsx       # Auto-discovered page → route /
├── vite.config.js             # Vite build configuration (outDir: frontend/js/.vite)
└── package.json               # NPM dependencies & scripts
