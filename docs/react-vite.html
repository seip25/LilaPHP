Frontend Architecture

React 19 & Vite Engine

LilaPHP pairs PHP 8.4+ server-side pre-rendering with React 19 SPA client-side hydration, Vite HMR, and ultra-clean declarative view configuration.

Decoupled Architecture & Client-Side SPA

LilaPHP cleanly decouples the PHP 8.4 API backend from the React 19 SPA frontend using a direct HTML loading model:

  • Standalone Entry Point: frontend/index.html serves as the primary entry point for all web routes, eliminating PHP server-side template wrappers.
  • Client-Side SPA Routing: Nginx and the PHP front controller automatically fall back web routes (like /, /routes, /about) to frontend/index.html so React Router handles UI states in the browser.
  • Vite HMR & Fast Bundling: Loads frontend/src/main.jsx directly during development and outputs optimized static bundles to frontend/js/.vite/ for production deployment.
