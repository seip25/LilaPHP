Frontend Architecture

React 19 & Vite Engine

LilaPHP pairs PHP 8.4+ server-side pre-rendering with React 19 SPA client-side hydration, Vite HMR, and ultra-clean declarative view configuration.

Hybrid Architecture & Lifecycle

Unlike traditional SPAs that load empty HTML or heavy node-based SSR setups, LilaPHP uses a zero-latency hybrid workflow:

  • Clean Route Configuration: backend/views/index.php contains only declarative route SEO configuration arrays and middleware flags, keeping application logic entirely inside \Core\ViewEngine.
  • Server-Side Middleware Guards: Before sending HTML, \Core\ViewEngine checks if the requested route is marked as protected ('protected' => true). If unauthenticated, it issues an immediate 302 HTTP header redirect to prevent screen flicker.
  • Development HMR & React Refresh: In development, \Core\ViewEngine automatically injects the Vite React Refresh preamble script prior to loading /@vite/client and frontend/src/main.jsx on port 5173.
  • Production Asset Cache: In production (php cli.php docker prod or php cli.php build:react), Vite compiles static bundles into frontend/js/.vite/ and pre-caches asset tags in _core/cache/build_cache.php for 0ms lookup latency.

Route SEO & Middleware Usage

To add routes, dynamic titles, meta descriptions, protected session guards, or custom authentication callbacks, edit backend/views/index.php: 

<?php

use Services\AuthService;

$seoRoutes = [
    '/' => [
        'title' => 'LilaPHP | High-Performance React & PHP 8.4 Framework',
        'description' => 'Ultra-fast PHP 8.4 API engine integrated with React 19.',
        'keywords' => 'PHP 8.4, React 19, Vite, High Performance',
    ],
    '/dashboard' => [
        'title' => 'Dashboard | LilaPHP',
        'description' => 'Protected administrative control panel.',
        'protected' => true,
        'redirectTo' => '/login',
        'callback' => fn() => AuthService::validateAuth(autoEmit401: false),
    ],
];

\Core\ViewEngine::render($seoRoutes);

Project Directory Layout

├── _core/
│   ├── ViewEngine.php         # Layout engine, asset resolver & middleware guard
│   └── cache/
│       └── build_cache.php    # Compiled production Vite script & CSS tags
├── backend/
│   └── views/
│       └── index.php          # Declarative SEO & route middleware configuration
├── frontend/
│   ├── js/
│   │   └── .vite/             # Vite production build output directory
│   └── src/
│       ├── main.jsx           # React Router DOM entry point
│       ├── App.jsx            # Main layout wrapper
│       └── pages/
│           └── Home.jsx       # Primary Home component
├── vite.config.js             # Vite build configuration (outDir: frontend/js/.vite)
└── package.json               # NPM dependencies & scripts
