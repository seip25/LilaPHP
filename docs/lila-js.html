LilaPHP

Lila.js — Micro Frontend Engine

lila.js is a zero-dependency, high-performance (~350 lines) JavaScript library designed for LilaPHP static frontends. It provides island reactivity, single-page application (SPA) hash routing, template expressions, and deep proxy state management.

Core API Methods

Lila.mount(target, config)

Mounts a reactive component onto any HTML container. Accepts a CSS selector or DOM element. 

const instance = Lila.mount('#widget', {
    state: () => ({ count: 0 }),
    template: (s) => Lila.html`<button data-action="inc">Count: ${s.count}</button>`,
    actions: {
        inc: ({ state }) => state.count++
    },
    onMount: (state) => console.log('Component mounted!'),
    onDestroy: (state) => console.log('Component destroyed!')
});

Lila.route(path, handler) & Lila.start(selector, options)

Registers hash-based routes (#/). Lila.start kicks off the router and optionally auto-installs PWAs via Service Worker! 

Lila.route('/', {
    state: () => ({ title: 'Welcome Home' }),
    template: (s) => Lila.html`<h1>${s.title}</h1>`
});

Lila.start('#app', { 
    transition: 'fade',
    pwa: {
        worker: '/sw.js',      // Auto-registers service worker
        installPrompt: true    // Captures PWA install prompt for Lila.promptInstall()
    }
});

Lila.beforeRoute(hook) & Lila.navigate(path, isExternal)

Global middleware for Auth Guards. Use navigate to change routes or redirect externally. 

Lila.beforeRoute = async (path, query) => {
    if (path.startsWith('/admin')) {
        const auth = await Lila.fetch('/api/auth/check');
        if (!auth.ok) {
            Lila.navigate('/login'); // Internal hash redirect to #/login
            // Lila.navigate('/login.html', true); // Or force absolute external redirect
            return false; // Cancel navigation
        }
    }
    return true; // Allow navigation
};

Lila.Validator.validate(data, schema, options)

Powerful client-side validation ported from the backend. Supports multi-language. 

const result = Lila.Validator.validate(
    { email: 'bad_email', age: 15 },
    {
        email: { required: true, email: true },
        age: { min: 18 }
    },
    { lang: 'en', callback: (res) => console.log(res) }
);
// result.success === false
// result.errors = [{ field: 'email', message: 'email must be a valid email' }, ...]

Lila.store(name, initial)

Creates or retrieves a named global reactive store shared across independent components. 

const cart = Lila.store('cart', { items: [] });

// Subscribe from anywhere
cart.$subscribe((key, value) => {
    console.log('Cart updated:', key, value);
});

Lila.fetch(url, options)

Async wrapper around native fetch with JSON headers and automatic status verification. 

Lila.mount('#login-form', {
    state: () => ({ email: '', password: '' }),
    actions: {
        submit: async (ctx) => {
            try {
                // Automatically JSON stringifies the body!
                const res = await Lila.fetch('/api/login', {
                    method: 'POST',
                    body: { 
                        email: ctx.state.email, 
                        password: ctx.state.password 
                    }
                });
                
                Lila.navigate('/dashboard');
            } catch (err) {
                console.error("Login failed", err);
            }
        }
    }
});

DOM Template Directives

Directive Description Example
data-model Two-way data binding for input, checkbox, radio, textarea <input data-model="username" value="${s.username}">
data-action Attaches click or submit event handler defined in component actions. Access data-* via ctx. <button data-action="save" data-id="${s.id}">Save</button>
data-link Intercepts click for hash route navigation without reloading <a href="#/profile" data-link>Profile</a>

ES6 Literals & Morphing (No proprietary attributes!)

Lila.js uses an internal DOM morphing algorithm. Instead of learning custom proprietary attributes like data-each or data-if, you just use native JavaScript template literals with Lila.html!

Editor Tip: For VS Code, install the es6-string-html or lit-html extension. It will instantly add syntax highlighting and autocomplete to your html`...` blocks! 

const { html } = Lila;

// 1. Conditionals (If/Else)
html`
  ${ s.isLoading ? html`<p>Loading...</p>` : html`<p>Done!</p>` }
`

// 2. Loops (Each)
html`
  <ul>
    ${ s.items.map(item => html`<li>${item.name}</li>` }
  </ul>
`

Real-World Examples

Global Stores (Cart Example)

You can decouple your business logic using Lila.store(). Components can read, mutate, and subscribe to stores. When a store mutates, we manually update our component state to trigger a render. 

const cart = Lila.store('cart', { items: [] });

// 1. A component that modifies the store
Lila.mount('#product-list', {
    state: () => ({ products: [{ id: 1, name: 'Keyboard' }] }),
    template: (s) => Lila.html`
        <div>
            ${ s.products.map(p => Lila.html`
                <div>
                    ${p.name}
                    <button data-action="buy" data-id="${p.id}">Buy</button>
                </div>
            ` }
        </div>
    `,
    actions: {
        buy: (ctx) => {
            let item = ctx.state.products.find(p => p.id == ctx.id);
            // Push directly to the global store!
            cart.items.push(item); 
        }
    }
});

// 2. A component that subscribes to the store
Lila.mount('#cart-badge', {
    state: () => ({ count: 0 }),
    template: (s) => Lila.html`<span>Items in Cart: ${s.count}</span>`,
    onMount: (state) => {
        // Subscribe to global cart mutations
        return cart.$subscribe(() => {
            // Update local state, triggering a morphing re-render
            state.count = cart.$raw.items.length; 
        });
    }
});

PWA Auto-Installer (Service Worker)

Lila.js can automatically register your Service Worker and intercept the browser's native install prompt. Just add a standard <link rel="manifest" href="/manifest.json"> to your HTML head, and configure Lila.start. 

// 1. Configure Lila.start
Lila.start('#app', {
    pwa: {
        worker: '/sw.js',
        installPrompt: true
    }
});

// 2. Add an Install Button to your components!
Lila.mount('#install-banner', {
    template: () => Lila.html`
        <button data-action="install">Install SPA App 📲</button>
    `,
    actions: {
        install: async () => {
            const accepted = await Lila.promptInstall();
            if (accepted) console.log("User installed the app!");
        }
    }
});

Form Validation with State

Using Lila.Validator to validate forms before submitting. The errors are pushed into the component state for reactive DOM morphing. 

Lila.mount('#contact-form', {
    state: () => ({ email: '', message: '', errors: [] }),
    template: (s) => Lila.html`
        <form data-action="submit">
            <input data-model="email" value="${s.email}" placeholder="Email...">
            <input data-model="message" value="${s.message}" placeholder="Message...">
            
            ${ s.errors.length > 0 ? Lila.html`
                <ul style="color: red">
                    ${s.errors.map(err => Lila.html`<li>${err.message}</li>`}
                </ul>
            ` : '' }
            
            <button type="submit">Send</button>
        </form>
    `,
    actions: {
        submit: (ctx) => {
            // Validate the current state
            Lila.Validator.validate(ctx.state, {
                email: { required: true, email: true },
                message: { required: true, min: 10 }
            }, {
                lang: 'es', // Spanish error messages
                callback: (res) => {
                    // Update state errors (Morphing will re-render them)
                    ctx.state.errors = res.errors;
                    
                    if (res.success) {
                        alert("Form is valid!");
                    }
                }
            });
        }
    }
});

🔥 The "All-in-One" Architecture Pattern

Here is a complete example combining Auth Guards (beforeRoute), Two-Way Binding, Validation, Lila.fetch, and PWA Installation. 

const { html } = Lila;

// 1. GLOBAL AUTH GUARD
// Intercepts all routes starting with /admin
Lila.beforeRoute = async (path, query) => {
    if (path.startsWith('/admin')) {
        const auth = await Lila.fetch('/api/auth');
        if (!auth.ok) {
            Lila.navigate('/login'); // Send to login
            return false;
        }
    }
    return true;
};

// 2. LOGIN ROUTE (Validation & Fetch)
Lila.route('/login', {
    state: () => ({ email: '', pass: '', error: null, loading: false }),
    template: (s) => html`
        <form data-action="login">
            <h2>Login</h2>
            <input data-model="email" value="${s.email}" placeholder="Email">
            <input type="password" data-model="pass" value="${s.pass}" placeholder="Password">
            
            ${ s.error ? html`<p style="color:red">${s.error}</p>` : '' }
            
            <button type="submit" ${s.loading ? 'disabled' : ''}>
                ${ s.loading ? 'Wait...' : 'Enter' }
            </button>
        </form>
    `,
    actions: {
        login: (ctx) => {
            const v = Lila.Validator.validate(ctx.state, {
                email: { required: true, email: true },
                pass: { required: true }
            });
            
            if (!v.success) {
                ctx.state.error = v.errors[0].message; // Show first error
                return;
            }
            
            ctx.state.loading = true;
            Lila.fetch('/api/login', { method: 'POST', body: ctx.state })
                .then(res => Lila.navigate('/admin'))
                .catch(err => ctx.state.error = "Invalid credentials")
                .finally(() => ctx.state.loading = false);
        }
    }
});

// 3. ADMIN ROUTE (PWA Install Button)
Lila.route('/admin', {
    state: () => ({}),
    template: () => html`
        <div>
            <h1>Secret Dashboard</h1>
            <button data-action="installPWA">Install to Desktop</button>
        </div>
    `,
    actions: {
        installPWA: () => Lila.promptInstall()
    }
});

// 4. BOOTSTRAP SPA & PWA
Lila.start('#app', { 
    pwa: { worker: '/sw.js', installPrompt: true }
});

Two-Way Form Binding

data-model handles the input listeners. By rendering the state inside the value attribute, the DOM morpher natively preserves the user's focus and cursor position! 

Lila.mount('#profile', {
    state: () => ({ name: '', agree: false }),
    template: (s) => Lila.html`
        <form data-action="save">
            <input data-model="name" value="${s.name}" placeholder="Name...">
            
            <label>
                <input type="checkbox" data-model="agree" ${s.agree ? 'checked' : ''}>
                I agree to the terms.
            </label>
            
            <button type="submit" ${!s.agree ? 'disabled' : ''}>Submit</button>
            
            ${ s.name ? Lila.html`<p>Typing: ${s.name}</p>` : '' }
        </form>
    `,
    actions: {
        save: (ctx) => {
            // The submit event is automatically prevented (e.preventDefault)
            console.log('Saved:', ctx.state.name);
        }
    }
});
