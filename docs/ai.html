Advanced Features

Universal AI & LLM Engine

Zero-overhead, multi-provider AI client built into _core/AI.php supporting DeepSeek (with automated model fallback), Google Gemini, OpenAI, Anthropic Claude, and local Ollama.

Quick AI Prompt Example

<?php

use Core\AI;

// 1. Simple text generation using default provider
$answer = AI::text("Explain database indexing in simple terms.");

// 2. Global helper shortcut
$summary = ai("Summarize the following legal text: " . $contractText);

// 3. Structured JSON extraction with automatic decoding
$profile = AI::json("Generate a mock user profile with name, email, and occupation.");
// Returns: ['name' => 'Alice Johnson', 'email' => 'alice@example.com', 'occupation' => 'Software Architect']

Supported AI Providers

🚀 DeepSeek AI

Direct integration with api.deepseek.com. Supports deepseek-v4-flash, deepseek-chat, and deepseek-reasoner with automatic fallback. 

$res = AI::deepseek($prompt, [
    'model' => 'deepseek-v4-flash',
    'fallback_model' => 'deepseek-chat',
    'system' => 'Eres un asistente contable en Uruguay.'
]);

✨ Google Gemini

Supports Gemini 2.0 Flash, Gemini 2.0 Pro, Gemini 1.5 Flash/Pro with structured JSON output and system instructions. 

$res = AI::gemini($prompt, [
    'model' => 'gemini-2.0-flash',
    'json_mode' => true
]);

🧠 OpenAI

Supports GPT-4o, GPT-4o-mini, o1, and o3-mini. 

$res = AI::openai($prompt, [
    'model' => 'gpt-4o-mini',
    'temperature' => 0.5
]);

🦙 Ollama (Local & Private)

Zero API key required. Connects directly to local Ollama instance running Llama 3, Mistral, Qwen, or DeepSeek-R1. 

$res = AI::ollama($prompt, [
    'model' => 'deepseek-r1',
    'base_url' => 'http://localhost:11434'
]);

Built-in AI Rate Limiting

Protect your public AI chat endpoints against quota abuse with per-minute and per-day rate limits: 

<?php
// backend/routes/chat.php

use Core\AI;
use Core\Request;
use Core\Response;

$ip = Request::ip();
$limit = AI::checkRateLimit($ip, limitPerMinute: 6, limitPerDay: 30);

if (!$limit['allowed']) {
    Response::json(['error' => $limit['error']], 429);
    exit;
}

$message = input('message');
$reply = AI::text($message, [
    'provider' => 'deepseek',
    'system' => 'Eres un asistente virtual formal y profesional.'
]);

Response::json(['reply' => $reply]);
