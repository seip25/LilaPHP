LilaPHP

CLI & Migrations

LilaPHP includes a powerful CLI tool for managing database migrations and seeders. Supports SQLite, MySQL, and PostgreSQL with automatic schema generation from model definitions.

Essential Command Rule

The `cli.php` tool is located directly in the root directory alongside `index.php`. To execute CLI operations, run `cli.php` from your project root or via Docker.

# Option A: Local PHP / Terminal
php cli.php [command]

# Option B: Docker dev container
docker exec -it lilaphp_dev_cli php /var/www/html/cli.php [command]

Database Configuration

Configure your database provider in .env: 

# SQLite (Default)
DB_PROVIDER="sqlite"
DB_NAME="lila"

# MySQL
DB_PROVIDER="mysql"
DB_NAME="lila"
DB_USER="root"
DB_PASSWORD=""
DB_HOST="localhost"
DB_PORT="3306"

# PostgreSQL
DB_PROVIDER="pgsql"
DB_NAME="lila"
DB_USER="postgres"
DB_PASSWORD=""
DB_HOST="localhost"
DB_PORT="5432"

Migration Commands

migrate [--refresh] Primary Schema Sync

Automatically inspects all database models (`backend/models/*.php`) and synchronizes MySQL/SQLite tables in real time based on model definitions. Use `--refresh` to drop existing tables and re-run migrations from scratch. 

# Synchronize database tables
php cli.php migrate

# Drop all tables and re-synchronize from scratch
php cli.php migrate --refresh
health Microsecond System Diagnostics

Runs microsecond system diagnostics inspecting MySQL connectivity, APCu RAM status, Redis cluster health, OPcache preloading, and disk storage space. 

php cli.php health

Database Seeders

seed

Executes database seeding scripts located inside `backend/seeders/` to populate your API database with initial or test records (`O(1)` bulk insert). 

php cli.php seed

Route & Component Generators

make route <path>

Generates a new file-based API route inside `backend/routes/` with standard GET/POST handling and JSON response scaffolding. 

php cli.php make route v1/checkout

Creates `backend/routes/v1/checkout.php` automatically.

make model <Name>

Generates a new API database Model inside `backend/models/` equipped with table schema attributes for `migrate` synchronization. 

php cli.php make model Invoice

Background Workers & Docker Management

task:work

Starts a continuous background worker daemon consuming asynchronous tasks from Redis (`lilaphp:jobs`). Ideal for running email queues and heavy background processing without blocking API routes. 

php cli.php task:work
ws:serve <port> [-d|stop|status|restart]

Boots or controls the real-time Workerman WebSocket server daemon (`Socket.IO` style with Redis Pub/Sub). You can run it in background daemon mode (`-d`) or stop it cleanly (`stop`). 

# Start WebSocket server in background daemon mode (-d)
php cli.php ws:serve 8001 -d

# Stop the running background WebSocket daemon
php cli.php ws:serve stop 8001

# Check worker status and active connections
php cli.php ws:serve status 8001
docker [dev|prod|stop|ps|stats|logs|exec-mysql]

Orchestrates your Docker container cluster (`Nginx`, `PHP-FPM`, `MySQL`, and `Redis`), streams real-time CPU/RAM stats filtered for project containers, and provides interactive MySQL CLI access or raw SQL query execution. 

# Launch development environment
php cli.php docker dev

# Stream real-time CPU & RAM stats filtered for LilaPHP containers
php cli.php docker stats

# Open interactive MySQL CLI inside DB container
php cli.php docker exec-mysql

# Execute raw SQL query directly on MySQL database
php cli.php docker exec-mysql "SELECT id, name FROM products LIMIT 5"

System Optimization & Security Commands

benchmark

Runs real server-side OS-level load tests using asynchronous curl_multi handles. Supports --url=, --concurrency=, and --duration= flags with live Redis synchronization to /debug.html.

optimize

Pre-caches `.env` settings to `OPcache` memory and flushes APCu/Redis pools (`Performance First`). Run this after deploying updates to production.

key:generate

Generates a cryptographically secure 256-bit `APP_KEY` inside `backend/.env` for AES token encryption and JWT signing.

help

Displays all available commands and syntax usage for `cli.php`.
