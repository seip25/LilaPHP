LilaPHP

Admin Portal

Built-in

LilaPHP includes a zero-configuration Admin Portal that automatically discovers your models and provides a responsive dashboard to manage your data.

Auto-Discovery

Any class extending BaseModel inside the /models directory is automatically detected and added to the sidebar. Scoping discovery to this folder ensures maximum security and performance.

Secure by Default

Powered by the #[Admin] attribute which handles authentication, session validation, and dashboard routing middleware automatically.

1. Create the Endpoint

// routes/admin.php
use Core\{App, Admin,GET,POST};

$app = new App();

#[GET] #[POST] #[Admin]
function portal() {
    // Logic is handled automatically by the #[Admin] attribute
}

$app->add('portal');
$app->run();

2. Add an Admin User

Run the following command to create your first administrative account:

php app/cli.php admin:add
