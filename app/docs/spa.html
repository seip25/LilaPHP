LilaPHP

SPA Support

Beta

LilaPHP features a powerful, built-in Single Page Application (SPA) engine that enables instant, seamless transitions between Twig-rendered pages.

Hybrid Navigation

Intercepts internal links and performs partial DOM updates using JSON payloads. It combines server-side security (session validation, CSRF) with frontend speed.

Intelligent Resource Loading

Automatically extracts and re-injects missing scripts or styles into the <head>, ensuring dynamic dependencies (like Vite modules) load only when needed.

How to enable

<!-- 1. Use the main content container in base.twig -->
<main id="lila-spa-content">
    {% block content %}{% endblock %}
</main>

<!-- 2. Use the dynamic layout in your templates -->
{% extends layout | default("base.twig") %}

Fail-safe Mechanism: If a request times out (5s) or fails with a server error, the engine automatically falls back to a traditional window.location.href reload.
