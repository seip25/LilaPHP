LilaPHP

Translations & Routing

Multi-language support out of the box using standardized 2-letter ISO codes (es, en, pt, etc.). Translation files live in locales/.

en.php

locales/ 
return [
  "welcome" => "Welcome!",
  "login" => [
      "title" => "Login"
  ]
];

Usage (Twig) 

<h1>{{ translate("welcome") }}</h1>
<h2>{{ translate("login.title") }}</h2>

Single Language Mode

Configuration

If your application only supports a single language, you can disable the entire translation system. This simplifies routing and removes language prefixes from your URLs.

1. Global Configuration (.env)

TRANSLATE=false

2. Per-Instance Configuration

$app = new App(['translate' => false]);

Key Effects:

  • Clean URLs: The url() helper will NOT prepend prefixes like /es/.
  • No Virtual Routing: Language detection from the URL segment is skipped.
  • Skip set-lang: The ?set-lang=true logic is completely bypassed.
  • Single Sitemap: The CLI generator will only include URLs without language segments.

Virtual Language Routing

LilaPHP supports language-prefixed URLs (Short SEO URLs) without physical directories. When a user visits a URL like /es/dashboard, the framework:

  • Detects the es prefix.
  • Automatically sets the session lang to es.
  • Transparently routes the request to the dashboard/index.php endpoint.

This works out of the box with Apache via .htaccess. For Nginx, see the Production section.

SEO-Aware URL Helper

The url() helper in Twig automatically prepends the current language prefix to your links, ensuring users stay within their selected language. 

<!-- If current lang is 'es' -->
<a href="{{ url('contact') }}"> ... </a>
<!-- Renders: <a href="http://domain.com/es/contact"> ... </a> -->

Language Switcher

Automatic

Switch language on-the-fly by passing set-lang=true. The framework will update the session and optionally perform a localized redirect. 

<!-- Switch to English -->
<a href="?set-lang=true&lang=en">English</a>

<!-- Switch to Portuguese (Brazil) -->
<a href="?set-lang=true&lang=pt-br">Português</a>
