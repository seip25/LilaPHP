LilaPHP

SEO & Sitemap

New

LilaPHP provides a declarative way to handle SEO metadata using PHP 8 Attributes. This information is automatically injected into Twig templates.

Usage with #[SEO] Attribute 
use Core\SEO;
use Core\GET;

#[GET]
#[SEO(
    title: "Beautiful Framework",
    description: "Documentation for LilaPHP SEO features",
    keywords: "php, seo, sitemap, framework",
    image: "https://domain.com/og-image.jpg"
)]
function index($req, $res) {
    return $res->render("home");
}

Multilingual Dynamic SEO

Instead of hardcoding strings, you can use the key parameter to pull localized SEO data from locales/seo.php automatically based on the user's active session language.

1. Define in seo.php 
// locales/seo.php
return [
    "home" => [
        "en" => [
            "title" => "Welcome",
            "descriptionMeta" => "Hello world",
            "keywordsMeta" => "welcome, hello"
        ],
        "es" => [
            "title" => "Bienvenido",
            "descriptionMeta" => "Hola mundo",
            "keywordsMeta" => "bienvenido, hola"
        ]
    ]
];
2. Use in your Controller
use Core\SEO;
use Core\GET;

#[GET]
#[SEO(key: "home")] // Auto-resolves based on language
function index($req, $res) {
    return $res->render("home");
}

Performance Caching

In production (DEBUG=false), SEO attributes are cached to avoid Reflection overhead. The system uses app/cache/route_attribute_cache.php to store this metadata.

Multilingual Sitemap

Generate a compliant sitemap.xml with hreflang support for all your physical endpoints and discovered languages. This command also creates or updates your robots.txt to include the Sitemap: directive automatically. 

php app/cli.php sitemap:generate
